Spinner em botões

Spinners também podem ser utilizados dentro de botões para indicar que uma ação está sendo processada.

Como funcionam os Spinners?

Os Spinners do Bootstrap são componentes prontos que utilizam classes CSS para criar animações de carregamento.

Principais classes

  • spinner-border — cria um Spinner com uma borda giratória.
  • spinner-grow — cria um Spinner com efeito de crescimento.
  • spinner-border-sm — cria uma versão menor do Spinner de borda.
  • spinner-grow-sm — cria uma versão menor do Spinner crescente.
  • text-primary, text-success, text-danger etc. — permitem alterar a cor.

Exemplo prático

Um Spinner pode ser utilizado enquanto o site aguarda uma resposta ou realiza alguma tarefa.
